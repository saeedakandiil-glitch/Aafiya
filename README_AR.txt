حزمة عافية الجاهزة للنشر على Netlify
====================================

محتويات الحزمة:
- index.html: صفحة البداية التي تتيح اختيار المنصة.
- Aafiya_Family_v2_0.html: منصة عافية أسرة.
- Aafiya_Mental_Wellbeing_v2_8.html: منصة عافية للبالغين.

طريقة النشر:
1) فك ضغط ملف Aafiya_Netlify_Ready.zip.
2) ارفع المجلد الناتج (أو محتوياته معًا) إلى Netlify Drop / منطقة النشر اليدوي في Netlify.
3) تأكد أن index.html والملفين الآخرين موجودون في جذر مجلد النشر نفسه.
4) بعد النشر، افتح رابط الموقع؛ ستظهر صفحة اختيار المنصة.

الروابط بعد النشر:
- الصفحة الرئيسية: /
- عافية أسرة: /Aafiya_Family_v2_0.html
- عافية للبالغين: /Aafiya_Mental_Wellbeing_v2_8.html

ملاحظات:
- لا يوجد ملف إعدادات build مطلوب لهذه الحزمة؛ إنها صفحات HTML ثابتة.
- لا تحذف index.html إذا أردت أن تظهر صفحة الاختيار عند فتح رابط الموقع الأساسي.
- لا تعتبر عدم إرسال إجابات الاستبيان من JavaScript ضمانًا بأن مزود الاستضافة لا يعالج بيانات تقنية عن الزيارات مثل عناوين IP وسجلات الطلبات. راجع إعدادات وسياسة Netlify.
- لا تضف أدوات تحليلات أو سكريبتات خارجية دون مراجعة أثرها على الخصوصية.
